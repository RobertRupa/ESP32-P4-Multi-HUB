# C6 ESP-Hosted OTA Audit

## Authorization and route

- Date: 2026-11-07
- Authorization: user approved erasing/replacing device firmware and testing regardless of existing contents.
- Target co-processor: integrated ESP32-C6, currently observed ESP-Hosted firmware 2.3.2.
- Update route: P4 host USB Serial/JTAG on `/dev/ttyACM0` stages the C6 image into P4 partition `c6_fw`; a manually confirmed P4 console command streams it to C6 over the established SDIO link.
- The updater does not run automatically at boot. It requires `c6_ota CONFIRM-C6-ESP-HOSTED-3.1.0` and records attempt/result metadata in P4 NVS.
- No Wi-Fi credentials or external OTA server are used.

## Procedure

1. Flash the P4 updater using `/dev/ttyACM0`; do not run `erase-flash`. The final native-REPL image booted and reached the console prompt.
2. Stage the C6 application image as raw data in P4 partition `c6_fw` at `0x410000` using esptool `write_flash --force`; read the region back and compare SHA-256.
3. Open the P4 USB Serial/JTAG console and type the exact confirmation command shown above.
4. The P4 validates the image, persists an NVS audit state, streams OTA chunks over SDIO, then restarts to verify the reported CP version.
